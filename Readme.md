## Features

- Premium black-and-white design
- Responsive mobile-friendly layout
- Smooth scrolling animations
- UGC portfolio showcase
- AI video advertising services
- Product advertisement showcase
- About the founder section
- Contact through email
- Mobile navigation menu

## How to Run

1. Download the project.
2. Extract the ZIP file.
3. Open the folder in Acode.
4. Open `index.html`.
5. Preview in your browser.

## Customization

Before publishing:

1. Replace `YOUR_EMAIL@gmail.com` with your agency email.
2. Add your real UGC advertisement videos and images.
3. Update portfolio projects.
4. Add your social media links.
